# 每日 Summary 模板（四章精简版）

本模板用于生成 `投资新闻归档/YYYY-MM/YYYY-MM-DD/summary_YYYY-MM-DD.md`。

日报是**组合监控、历史对比和证据定位的运行摘要**，只保留四章。复盘、逐基金状态、今日关注要点与数据附录**不再写入日报**，完整证据链、人读决策解释与运行清单全部由同日 HTML 承载。两者共享同一份 `raw_data/`、`item_summaries/` 和持仓快照。

> ⚠️ 日报自 2026-09-24 起收窄为四章。第五章「复盘与风险雷达」、第六章「逐基金状态复核与操作建议」、第七章「今日关注要点」、第八章「数据附录」已移除。不要自行补回这四章，也不要新增其他章节。

---

## 一、使用原则

### 1. 时间视角与数据口径

- 若日报在 `T` 日早晨生成，复盘对象是 `T-1` 的官方净值、大盘宽基指数与沪金99.99收盘、申万二级行业指数、北向单日与近 7 天窗口。
- 基金数据用前一交易日官方净值；上证、深成、创业板、沪深300、上证50和中证100/200/500/800/1000/2000/A500/全指/红利、科创50等宽基指数，沪金99.99与申万二级行业指数都只用前一交易日收盘数据。行业指数不与持仓基金建立一对一关联。任一申万行业数据未取得目标交易日结果时，必须明确留空或写明缺失，不得回退使用更早交易日数据；不使用估值、分析日当天行情或当天北向数据。
- 缺失字段必须明确标注缺口，禁止估算补写。

### 2. 分层与依赖关系

1. **事实源**：`raw_data/*.json`、`item_summaries/*.md`、`投资者行动/持仓情况.md`。HTML 和日报均不是事实源。
2. **日报**：保存完整核心持仓表、持仓变化、组合结论、新闻索引和市场快照，供下一轮快速比对。
3. **HTML**：保存完整新闻四段式、量能/ETF/行业全表、政策表、逐基金决策卡、复盘与风险提示、今日关注与建议摘要，以及数据附录。
4. 日报可以链接 HTML 与单条归档，但不得只剩一个 HTML 链接；HTML 路径必须写入日报头部元信息，供历史读取反查。

### 3. 书写纪律

- 基金必须写成"基金名称(代码)"全称；禁止裸代码、简称或代码前置。
- 不把市场信息机械改写成风险结论；不把政策观察直接写成建仓或交易指令。
- 触发价格线锚定持仓成本；成本未变时，不能因单日净值上涨而上移止盈/减仓线。
- 不机械拆空章节；每章只保留后续监控所必需的信息。
- **跨章去重**：同一事实只在一处展开。基金数字只在第一章核心表出现；宏观判断只在第三章；市场量能只在第四章；新闻只在第二章索引。其他位置只能引用编号或一句结论，不得复述数字。

## 三、各章节职责

### 一、核心指标速览与横向对比（完整保留）

本章是持仓与历史对比的稳定输入，必须包含：

- 份额大于 0 的全部基金核心表：官方净值、持有份额、当前持有金额、持仓成本、浮盈%、短期可比变化、组合占比。
- `持仓变化检测`：相对最近可比较 summary 的真实份额变化；无变化也必须明确写出。
- 2–3 句组合结论：当前强弱、稳定器状态、最需观察的仓位、为何不能直接改变动作。
- **异常横向比较**：只保留会改变动作或置信度的代理背离/相对强弱；全量代理表放 HTML。

近 1 月字段若原始数据没有可回溯值，明确写缺口，不推算。

### 二、近期重要新闻与政策（索引，不重写全文）

本章保留本轮所有 `item_summaries/` 的紧凑索引：

| 编号 | 事件锚点 | 本轮新增含义 | 归档 |
|---|---|---|---|
| 01 | 事件标题 | 对组合判断的最短用途与边界 | `item_summaries/01_xxx.md` |

- 单条归档才保存发布源、原始链接、事实、关联持仓、判断用途的完整字段。
- HTML `sec-2b` 展示完整新闻四段式。
- 北向、融资余额、成交额等脚本定量数据不得进入本章。

### 三、政策与宏观环境（结论卡）

只保留 2–4 条会影响组合判断的宏观/政策结论，且每条标明对应新闻索引或归档锚点；最后用一句话写环境判断及反向风险。

完整方向表放 HTML `sec-3b`。

### 四、宽基ETF与申万二级行业变动（市场信号快照）

必须保留：

1. 市场量能三项：全A（沪深京）成交额、北向单日/窗口、全市场融资余额及日变化。
2. 上证、深成、创业板、沪深300、上证50和中证100/200/500/800/1000/2000/A500/全指/红利、科创50等大盘宽基指数及沪金99.99的前一交易日收盘表现，以及申万二级行业强弱或背离信号。
3. 一句阶段判断与证据边界。

不复制全量 ETF 表、申万涨跌前后十和完整行业映射表；它们在 HTML `sec-3`，原始数据在 `market_momentum_YYYY-MM-DD.json`。

## 五、交付自检

- 四章标题齐全，顺序与骨架一致，没有第五章及以后的章节。
- 第一章核心表覆盖全部 active holdings；所有基金名称均为"基金名称(代码)"全称，裸代码扫描为 0。
- 第二章新闻索引数量 = `item_summaries_count`；每条均可定位归档。
- 第四章市场快照的定量数值可回溯至 `market_momentum`。
- 头部元信息含同日 HTML 路径。
- 同一事实未在多章复述：核心数字只出现在第一章，宏观判断只在第三章，量能只在第四章。
